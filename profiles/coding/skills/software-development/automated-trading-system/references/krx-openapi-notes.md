# KRX OPEN API Notes

## Rate Limit

| 항목 | Limit |
|------|-------|
| 무료 | 1초에 1회 |
| 유료 | tier별 스케일업 (최대 50req/sec) |

**중요**: 무료 티어가 매우 낮음. 실시간 사용 불가.

## 데이터 타입

| 데이터 | 실시간 여부 | 제공 시기 |
|--------|-------------|-----------|
| OHLCV (종목별 시세) | ❌ | 장 종료 후 T+1일 |
| 시장별 시세 | ❌ | 장 종료 후 |
| 시가총 ranking | ❌ | 장 종료 후 |

## 결론

- 일일 스캐닝에는 적합
- 인트라데이(실시간) 트레이딩에는 부적합
- 무료 티어의 1req/sec 제한으로 루프에서 사용하기 어려움
- 주식 스크리닝용으로 간헐적 호출만 권장
