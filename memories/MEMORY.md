Local LLM serving on this box (joons = 192.168.219.115, single host): llama.cpp `llama-server` runs behind a raw-TCP llama-proxy (front ports 11534-11538 → backends 1534-1538). Probe the FRONT port (11534) for resident/keep models, not the backend — hitting a raw-TCP proxy's backend port BOOTS the backend and defeats idle-unload. Keep flags live at ~/llama-proxy/keep/<front_port>; a present file suppresses the proxy idle-watchdog unload. llama-monitor (Flask, port 5002) at ~/.hermes/services/llama-monitor: /api/unload = `systemctl --user stop <unit>` (kills the process), /api/keep = toggles the keep file (no model action). Host GPU is NVIDIA GB10 = ARM (Grace) + unified memory: /proc/cpuinfo shows no x86 AVX flags, so AVX-512/AVX2-only engines (e.g. Strata decode kernels) may not run — verify on-device before committing. Hermes config is per-profile: ~/.hermes/profiles/<name>/config.yaml, so model.base_url changes are profile-scoped, not gateway-wide.
